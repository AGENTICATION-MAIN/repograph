# Dynamic Market Clearing & Shadow Price Discovery

Pactum enables autonomous multi-service market clearing without fiat currency:

## Shadow Exchange Ratios ($\lambda_{A:B}$)
The empirical shadow exchange ratio between two computational capabilities naturally emerges from the ratio of agreed trade quantities:
$$\lambda_{A:B} = \frac{q_A^*}{q_B^*}$$

For example:
- If 100 Stripe API Rate Limit tokens trade for 500 MB-sec of GPU VRAM, the emergent shadow exchange rate is:
  $$\lambda = 0.2\text{ API tokens per MB-sec GPU VRAM}$$
- These shadow prices adjust in real time based on cluster supply and demand fluctuations.
